🐾 Pawsitive Pet Academy Website

About the Project

Pawsitive Pet Academy is a website designed to provide information about pet care, training, and first aid. It aims to help pet owners access useful resources and learn more about caring for their pets.

Features

- Home page introducing Pawsitive Pet Academy
- Courses page with pet-related learning information
- First aid course information
- Fees page providing course fee information
- Contact page for enquiries
- Navigation between website pages
- Interactive functionality using JavaScript
- Styled layout using CSS

Technologies Used

- HTML5 — structures the website pages
- CSS3 — styles the website and layout
- JavaScript — adds interactive functionality
- Git — tracks changes to the source code
- GitHub — stores and manages the project repository

Project Pages

- "index.html" — home page
- "about.html" — about page
- "courses.html" — courses page
- "course-first-aid.html" — first aid course page
- "fees.html" — fees page
- "contact.html" — contact page

Getting Started

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open "index.html" in your browser, or use the Live Server extension in VS Code to run the website locally.
